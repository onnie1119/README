安裝多公司管理工具 管理工具測試連線 建立公司資料庫 主程式安裝

  管理工具測試連線

一、輸入安裝SQL Server資料庫時，所建立的執行個體
請輸入『具名執行個體』，名稱的來源由 Microsoft SQL Server 2022 Express過程中，自行設定的名稱 (預設為SQLExpress)

二、驗證SQL Server資料庫登入的密碼，請使用SQL Server的帳戶驗證，並且輸入安裝資料庫時，自行設定的密碼。

三、點選『測試連線』，與資料庫連線成功後。

四、請務必點選『確定』鍵，等待表單自動關閉，即可完成資料庫建立與連線。
