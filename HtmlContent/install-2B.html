安裝多公司管理工具 管理工具測試連線 建立公司資料庫 主程式安裝

  新增各別公司的資料庫

注意事項

一、往後每新增一間公司，都是直接從管理工具內新增資料庫即可。

二、新增公司資料庫前，請先至『系統工具』點選『重整現有資料庫』，避免重覆新增公司資料庫。

三、建立的公司名稱資料庫此「公司名稱」不可重複。

四、資料庫管理工具登入的預設帳號密碼是: 名稱為『sa』，密碼為您在安裝 SQL Server 執行個體時所設定的號碼。

STEP1:登入管理工具

完成管理工具測試連線後即可登入管理工具

STEP2:新增公司資料庫

(1) 點選【公司資料庫管理】。

(2) 先點選右下角『重整』，將現有SQL Server執行個體中的資料庫匯入管理工具。

(3) 點選右上角的『新增』。

(4) 輸入公司名稱與公司簡稱。

(5) 點選『新增』，即可完成資料庫建立。
